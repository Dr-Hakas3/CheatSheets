## **1. 概要**

**rlwrap（Readline Wrapper）** は、対話型コマンドラインプログラムにGNU Readlineの入力編集機能を追加するラッパーツールである。

Readlineを標準でサポートしていないプログラムでも、コマンド履歴やカーソル移動などの操作を可能にする。

特に、CTFやペネトレーションテストにおいて、Netcatを利用したリバースシェルの待ち受け時によく使用される。

## **2. 主な機能**

rlwrapが提供する主な機能は以下のとおり。

|機能|説明|
|---|---|
|コマンド履歴|↑ ↓ キーによる過去の入力の参照|
|履歴検索|Ctrl + R による入力履歴の検索|
|カーソル移動|← → キーによる入力位置の移動|
|行編集|入力済みコマンドの編集|
|入力補助|Readlineによる入力操作の改善|

## **3. 基本的な使い方**

```
rlwrap [コマンド]
```

コマンドの前にrlwrapを指定することで、そのプログラムにReadlineの機能を追加する。

### **Netcatでの使用例**

通常の起動：

```
nc -lvnp 4444
```

rlwrapを使用した起動：

```
rlwrap nc -lvnp 4444
```

後者では、Netcatの入力操作にコマンド履歴や行編集機能が追加される。

## **4. リバースシェルでの利用**

CTFなどでリバースシェルを待ち受ける場合、以下のように使用する。

```
rlwrap nc -lvnp 4444
```

rlwrapを使用することで、シェル操作時の入力補助が利用できる。

ただし、rlwrap自体にリモート側のTTYを生成する機能はない。

## **5. rlwrapとTTYの違い**

リバースシェルの操作性を改善する手法には、rlwrapとTTYの生成がある。両者は役割が異なる。

|ツール・コマンド|役割|
|---|---|
|rlwrap|ローカル側の入力編集・履歴管理|
|Python PTY|リモート側の擬似端末（PTY）の生成|
|stty|端末の動作設定|
|export TERM|端末タイプの環境変数を設定|

### **リモート側でPTYを生成する例**

```
python3 -c 'import pty; pty.spawn("/bin/bash")'
```

これはPythonの`pty`モジュールを利用して、リモート側に擬似端末を生成する処理である。

**重要な違い**

- rlwrap：ローカル側の入力操作を改善する
    
- Python PTY：リモート側に擬似端末を生成する
    

両者は併用可能だが、rlwrapを使用しただけでは完全なTTYにはならない。

## **6. インストール**

Kali Linuxの場合：

```
sudo apt update
sudo apt install rlwrap
```

バージョン確認：

```
rlwrap --version
```

## **7. まとめ**

- rlwrapはReadlineの入力編集機能を追加するラッパーツール。
    
- Netcatなどの対話型プログラムと組み合わせて使用できる。
    
- コマンド履歴、カーソル移動、入力編集などを利用できる。
    
- リモート側のTTYを生成する機能はない。
    

**基本コマンド**

```
rlwrap nc -lvnp 4444
```
