Wi-Fi認証方式・セキュリティ規格 総合一覧
1. セキュリティ規格の世代別比較
規格	認証方式	暗号化方式	主な特徴	セキュリティ
WEP	Open System / Shared Key	RC4	24bit IVを使用。鍵の再利用などに問題	脆弱
WPA	PSK / 802.1X	TKIP（RC4ベース）	WEPの問題を改善するために登場	旧式
WPA2	PSK / 802.1X	AES-CCMP（一般的）	強固な暗号化とEnterprise認証に対応	現在も普及
WPA3	SAE / 802.1X	AES-CCMP / GCMPなど	パスワード認証の強化、Enterpriseのセキュリティ向上	現行世代

2. 認証方式の詳細一覧
認証方式	対応規格	分類	認証の仕組み	特徴
Open System	WEP	Open	認証時にパスワード確認を行わない	WEP暗号化と併用可能
Shared Key	WEP	Open	WEPキーを使用したチャレンジレスポンス	認証過程で情報が漏れる問題
PSK	WPA / WPA2	Personal	事前共有パスワードで認証	一般家庭・小規模オフィス
SAE	WPA3	Personal	DragonflyベースのPAKE	オフライン辞書攻撃への耐性を強化
802.1X / EAP	WPA / WPA2 / WPA3	Enterprise	EAPとRADIUSを利用した認証	企業ネットワーク向け
OWE	Enhanced Open	Open	Diffie-Hellmanベースの鍵確立	パスワードなしで通信を暗号化

※OWEは厳密にはユーザー認証方式ではなく、オープンネットワーク向けの暗号化・鍵確立方式です。
3. 暗号化方式一覧
暗号化方式	使用規格	暗号アルゴリズム	特徴
WEP	WEP	RC4	IVが24bitで、鍵解析が容易
TKIP	WPA	RC4	WEPの問題を改善した旧式方式
CCMP	WPA2 / WPA3	AES	AES-CCMを使用。一般的な無線LAN暗号化
GCMP	WPA2 / WPA3	AES	Galois/Counter Modeを使用
OWE	Enhanced Open	AES-CCMPなど	暗号化のための鍵を接続ごとに確立

4. Enterprise認証（802.1X / EAP）の種類
EAP方式	認証方法	証明書	特徴・注意点
EAP-TLS	クライアント証明書	必須（クライアント・サーバー）	相互認証が可能。強固な方式
PEAP	TLSトンネル内で認証	サーバー証明書	内部認証にMSCHAPv2などを使用
EAP-TTLS	TLSトンネル内で認証	通常サーバー証明書	内部認証方式の選択肢が広い
EAP-MD5	Challenge-Response	不要	相互認証や通信保護が不十分
EAP-FAST	PACを使用	通常不要	Ciscoが開発した認証方式
EAP-SIM	SIM認証	不要	SIMの認証情報を利用

802.1Xの構成要素
構成要素	役割	具体例
Supplicant	認証を要求するクライアント	PC、スマートフォン
Authenticator	クライアントの接続を制御	AP、無線LANコントローラー
Authentication Server	認証処理を実施	RADIUSサーバー

学習上の重要ポイント
- ENC：どの世代のセキュリティ規格か
- CIPHER：何で暗号化しているか
- AUTH：どのような認証・接続方式を使用しているか
この3つを別々に理解することが重要です。

特に今後のWiFiChallengeLabでは、まず WPA2-CCMP-PSK と WPA3-CCMP-SAE の違いを深く理解し、その後 MGT（Enterprise認証）に進むのがおすすめです。
