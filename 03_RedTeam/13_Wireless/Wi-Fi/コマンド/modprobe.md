# `modprobe` **コマンド解説**

`modprobe` は、Linuxカーネルに**カーネルモジュール（Kernel Module）をロード・アンロードするコマンド**です。

特にKali Linuxで無線LANアダプタを操作する場合、Wi-Fiドライバの読み込み・切り替えなどで使用します。OSWP学習でも重要なコマンドです。

## **1. 基本構文**

```
modprobe [オプション] モジュール名
```

- `modprobe`：カーネルモジュールを管理するコマンド
    
- モジュール名：ロード・アンロードする対象
    

## **2. よく使うオプション**

|オプション|説明|
|---|---|
|`-v`|詳細な処理内容を表示|
|`-r`|モジュールをアンロード|
|`-a`|複数のモジュールを処理|
|`-n`|実際には実行せず動作を確認|
|`-f`|強制的にロード・アンロード|
|`--show-depends`|依存モジュールを表示|

## **3. 基本的な使用例**

### **① モジュールをロードする**

```
sudo modprobe ath9k
```

`ath9k` という無線LANドライバをカーネルにロードします。

### **② モジュールをアンロードする**

```
sudo modprobe -r ath9k
```

ロード済みの `ath9k` モジュールをアンロードします。

### **③ 詳細情報を表示する**

```
sudo modprobe -v ath9k
```

モジュールのロード時に実行される処理を表示します。

### **④ 実行せずにロード可否を確認する**

```
sudo modprobe -n -v ath9k
```

実際のロードは行わず、実行される処理を確認します。

## **4. 関連コマンド**

|コマンド|役割|
|---|---|
|`modprobe`|モジュールのロード・アンロード|
|`lsmod`|ロード済みモジュール一覧|
|`rmmod`|モジュールのアンロード|
|`insmod`|モジュールファイルを直接ロード|
|`modinfo`|モジュールの詳細情報|
|`dmesg`|カーネルログの確認|

例えば、無線LANドライバを確認する場合：

```
# ロード済みモジュールを確認
lsmod | grep ath

# ドライバの詳細情報
modinfo ath9k

# ドライバをロード
sudo modprobe ath9k

# カーネルログを確認
dmesg | tail -20
```

## **5. OSWP学習での利用例**

無線LANアダプタのチップセットによっては、使用するドライバを切り替える必要があります。

**無線LANドライバの操作イメージ**

**Linux Kernel**

カーネル

**ロード**

modprobe

ドライバ有効化

**アンロード**

modprobe -r

ドライバ解除

**Wi-Fiアダプタ**

無線LANデバイス

例えば：

```
sudo modprobe -r iwlwifi
sudo modprobe iwlwifi
```

これはIntel製無線LANで使用されるドライバのアンロード・再ロード例です。

※ 実行するとWi-Fi接続が切断されます。また、使用中のモジュールは依存関係などによってアンロードできない場合があります。

## **6. 覚えておくべきポイント**

- `modprobe` = カーネルモジュールの管理
    
- `modprobe モジュール名` = ロード
    
- `modprobe -r モジュール名` = アンロード
    
- `lsmod` = 現在ロードされているモジュールを確認
    
- `modinfo` = モジュールの情報を確認
    

**OSWP向けには、無線LANドライバの管理に使うコマンドとして覚えておくとよいです。**
