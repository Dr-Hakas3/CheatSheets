今回使っている **Wacker** は、Wi-Fiネットワークの認証セキュリティを検証するための無線セキュリティツールです。

特に、**WPA/WPA2/WPA3の認証方式やSAEに関連する攻撃・検証**を行う用途で使われます。

## **今回構築したものの役割**

| ツール            | 役割                 |
| -------------- | ------------------ |
| Wacker         | Wi-Fi認証の検証・攻撃を実行する |
| wpa_supplicant | APとの認証処理を担当する      |
| wordlist       | 認証に使用する候補パスワード     |
| wlan60 / wlan3 | 無線インターフェース         |

## **なぜ専用版をコンパイルしたのか？**

通常のKali標準版 `wpa_supplicant` ではなく、Wackerに同梱されている専用版をビルドしたのは、Wackerが必要とする改変・機能を利用するためです。

つまり、Wacker単体でWi-Fi認証を処理するのではなく、専用の `wpa_supplicant` と連携して動作します。

## **ここで押さえたいこと**

Wackerは、通常のWi-Fi接続を行うためのツールではありません。

**Wi-Fiの認証処理を利用して、パスワード認証の安全性を検証するための攻撃ツール**と理解してください。

次は、今回の `wifi-management` がWPA3-SAEを使っている理由と、Wackerがどのような仕組みで認証を検証するのかを理解すると、演習の目的がつながります。
