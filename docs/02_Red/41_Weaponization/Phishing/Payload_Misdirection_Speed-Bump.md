# 受信メールフィルターの役割
メールフィルタリング製品は添付ファイルを精査するため、ペイロードを配信する際には回避技術を活用する必要がありる。EXE**ファイル**や **SCR**ファイルなど、特定の添付ファイルは特に精査され、悪意のあるファイルと判断される。製品によっては、Officeドキュメント、PDFファイル、アーカイブファイル（ZIPファイルなど）、スクリプトファイル、そしてこれらのファイルをホストする外部ドメインを指すハイパーリンクなど、その他の実行ファイル（または実行コードを含むファイル）も悪意のあるファイルと判断される場合がある。

# 悪意のあるOfficeマクロのリスクの特定
## [「Mark of the Web](https://en.wikipedia.org/wiki/Mark_of_the_Web)（MotW）」
外部ソースからファイルがダウンロードされた際にWindowsが設定するファイル属性。
WindowsのデフォルトのNTFSファイルシステムによって有効化され。
MicrosoftはMotW属性を持つすべてのドキュメントで実行されるマクロをデフォルトでブロックする。
