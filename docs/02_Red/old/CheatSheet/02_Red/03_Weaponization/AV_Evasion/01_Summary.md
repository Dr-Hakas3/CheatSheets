## ディスク上の回避
AVソフトを回避できる無料ツールは殆どない
- Enigma Protector (市販ツール)
#### 難読化ツール(Obfuscators)
##### パッカー
- UPX
#####  クリプターソフトウェア
実行コードを暗号的に改変し、実行時に元のコードを復元する復号スタブを追加します。この復号はメモリ内で行われ、ディスク上には暗号化されたコードのみが残ります。暗号化は、最も効果的なアンチウイルス（AV）回避手法の一つとして、現代のマルウェアにおいて基盤となっています。

## メモリ内回避
Windowsマシン上でウイルス対策製品を回避するためによく使われる手法
### インメモリインジェクション（ PEインジェクションとも呼ばれる）
#### リモート プロセス メモリ インジェクション
1. OpenProcess関数を使用して 、アクセス許可を持つターゲット プロセスへの有効なHANDLE を取得
2. HANDLE を取得したら、 VirtualAllocEx などの Windows API を呼び出して、そのプロセスのコンテキストにメモリを割り当てる
3. リモート プロセスでメモリが割り当てられたら、 WriteProcessMemoryを使用して、悪意のあるペイロードを新しく割り当てられたメモリにコピー
4. ペイロードが正常にコピーされると、通常はCreateRemoteThread APIを使用して別のスレッドでメモリ内で実行される

これは複雑に聞こえますが、後の例で同様の手法を使用して、PowerShell に重い処理を実行させ、ローカルのpowershell.exe インスタンスをターゲットとした非常に類似しているが簡略化された攻撃を実行します。
#### リフレクティブ DLL インジェクション 手法
- 攻撃者がプロセス メモリに保存した DLL をロード
- LoadLibrary APIを使用してディスクから悪意のある DLL をロードする 通常のDLL インジェクションとは異なる
- ディスクベースのDLLに依存しない独自のAPIを作成する必要がある

#### プロセス・ホローイング
1. 無害なプロセスを一時停止状態で起動
2. 起動後、プロセスのイメージはメモリから削除され、悪意のある実行イメージに置き換えられる
3. 最終的に、プロセスは再開され、正当なプロセスの代わりに悪意のあるコードが実行される

#### インラインフック
メモリを改変し、関数にフック（コード実行をリダイレクトする命令）を導入して、悪意のあるコードを指すようにする手法。悪意のあるコードが実行されると、フローは改変された関数に戻り、実行を再開します。これにより、元のコードのみが実行されたかのように見える。

フックは、よりステルス性の高いマルウェアであるルートキットでよく用いられる 。ルートキットは、ユーザー空間、カーネル、あるいはブート やハイパーバイザーといったOSの下位保護リングにおけるシステムコンポーネントを改変することで、マルウェア作成者に標的システムへの専用かつ永続的なアクセスを提供することを目的とし、ルートキットはフックを埋め込むために管理者権限を必要とするため、多くの場合、昇格されたシェルからインストールされるか、権限昇格の脆弱性を悪用してインストールされる。
