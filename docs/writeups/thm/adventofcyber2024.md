# Wi-Fiとは何か？

```
インターネットが私たちの生活において重要であることは、もはや説明不要と誰もが認めています。Wi-Fiは、私たちのデバイスをグローバルネットワークであるインターネットに接続する技術です。このシームレスなインターネット接続は、デバイスから見ると無線接続のように見えますが、実際、ある程度はそうなっています。私たちのデバイスは無線でルーターに接続され、ルーターは私たちとインターネットの間の橋渡し役を果たし、ルーターは有線接続でインターネットに接続されています。

Wi-Fiに接続するには、デバイスでWi-Fiをオンにすると、周囲にある利用可能なWi-Fiネットワークがすべて一覧表示されます。この一覧には、固有のSSID （ネットワーク名）でWi-Fi信号を発信しているアクセスポイント（多くの場合ルーター）が含まれています。正しいパスワード（事前共有キー（ PSK ）とも呼ばれます）を知っていれば、これらのネットワークのいずれにも接続できます。Wi-Fi経由でネットワークに正常に接続すると、そのネットワーク内でIPアドレスが割り当てられます。このIPアドレスは、あなたを一意に識別し、他のデバイスとの通信に役立ちます。これは、家族全員から信頼されている名前を与えられ、家族の一員になるようなものです。

下の画像は、一般的なWindowsマシンでOK443S SSIDに接続し、PSK（パスワード）を要求する際の画面例を示しています。
```

![](../../assets/images/Pasted%20image%2020260606050830.png)

```
一般的なWindowsマシンで、PSK（パスワード）を要求するSSID（OK443S）に接続すると、どのような画面が表示されるかを示します。

Wi-Fiに関する議論が盛んに行われている今、Wi-Fiはインターネットアクセスへの扉のように思えます。そして、Wi-Fi接続ごとにデバイスのネットワークが構築されます。よく知らない人を自分の家族の一員として受け入れるでしょうか？そう簡単にはいきませんよね。おそらく、家族の一員には特別な特権があり、部外者には決してその特権を与えたくないからでしょう。

組織におけるWi-Fiの重要な役割バイト・ザ・ドッグというキャラクター。
ほとんどの組織は、業務運営においてインターネットに依存しています。 全従業員が有線接続でインターネットに接続しようとすると、コスト、効率性、柔軟性の面で懸念が生じます。そのため、多くの組織は従業員をインターネットに接続するために、ネットワークにWi-Fiを利用しています。従業員が組織のネットワークに接続すると、相互接続されたデバイスの集合体が形成されます。ネットワーク内のデバイスは相互に通信し、要求をしたり、要求に応答したりすることができます。組織は、ネットワーク内での権限の悪用を防ぐため、信頼できるプロフェッショナルな従業員を採用する傾向があります。

しかし、組織外の悪意のある攻撃者は、組織のネットワークがWi-Fiをオンにした際に、そのネットワークのブロードキャストされたWi-Fi SSIDを依然として見ることができます。攻撃者はパスワードを知らないため、これは問題にならないように思えるかもしれませんが、攻撃者は実際には他にもいくつかの計画を抱えています。
```

# Wi-Fiへの攻撃

```
攻撃者がWi-Fi技術を悪用するために用いる手法はいくつかあります。ここで説明する手法は教育目的のみであり、ネットワークへの不正アクセスや侵害は違法であり、重大な法的結果を招く可能性があります。それを踏まえて、最も一般的な手法をいくつかご紹介します。
```

## 悪意のある双子攻撃:

```
この攻撃では、攻撃者は、信頼できるWi-Fiアクセスポイントのいずれかと似た名前の偽のアクセスポイントを作成します。もちろん、完全に同じ名前にすることはできません。信頼できるWi-Fiの名前が「Home_Internet」の場合、攻撃者は「Home_Internnet」など、区別しにくい類似の名前の偽のWi-Fiアクセスポイントを作成します。攻撃は、攻撃者が正規のWi-Fiアクセスポイントに接続しているすべてのユーザーに認証解除パケットを送信することから始まります。その後、ユーザーはネットワークから繰り返し切断されることになります。イライラしたユーザーは、トラブルシューティングのためにWi-Fiアクセスポイントのリストを開き、ほぼ同じ名前で信号強度が強い攻撃者のWi-Fiを見つけます。ユーザーはそれに接続しようとしますが、接続されると、攻撃者はインターネットとの間のすべてのトラフィックを監視できるようになります。
```

## 不正アクセスポイント：

```
この攻撃の目的は、イービルツイン攻撃と類似しています。この攻撃では、攻撃者は組織の物理的な施設内またはその近辺にオープンなWi-Fiアクセスポイントを設置し、電波強度の良いユーザーが利用できるようにします。組織内のユーザーは、デバイスがオープンWi-Fiに自動接続するように設定されている場合、誤ってこのネットワークに接続してしまう可能性があります。攻撃者は、ユーザーがこの不正アクセスポイントに接続した後、すべての通信を傍受することができます。
```

## WPS攻撃： 

```
Wi-Fi Protected Setup（WPS）は、複雑なパスワードを覚えなくても8桁のPINコードでWi-Fiに接続できるようにするために開発されました。しかし、この8桁のPINコードは、設定が安全でないネットワークでは脆弱です。この攻撃は、ルーターとのWPSハンドシェイクを開始し、PINコードに関連するデータを含むルーターの応答をキャプチャすることで行われます。この応答はブルートフォース攻撃に対して脆弱です。キャプチャされたデータの一部がブルートフォース攻撃によって解読され、PINコードと事前共有キー（PSK）が抽出されます。
```

## WPA/WPA2 クラッキング: 

```
Wi-Fi Protected Access (WPA) は、無線通信を保護するために開発されました。強力な暗号化アルゴリズムを使用していますが、このプロトコルのセキュリティは、事前共有キー (PSK) の長さと複雑さに大きく左右されます。WPA をクラッキングする際、攻撃者はまず Wi-Fi ネットワークの正規ユーザーに認証解除パケットを送信します。ユーザーが切断されると、ネットワークへの再接続を試み、その間にルーターとの 4 ウェイ ハンドシェイクが行われます。その間、攻撃者はアダプタをモニター モードにしてハンドシェイクをキャプチャします。ハンドシェイクがキャプチャされると、攻撃者はキャプチャしたハンドシェイク ファイルに対して総当たり攻撃または辞書攻撃を使用してパスワードを解読できます。
マクスキディはグリッチの方を見て、「グリッチ、どんな攻撃を披露するつもりなんだ？」と尋ねた。

グリッチは行ったり来たりした後、突然立ち止まり、「今日はWPA/WPA2クラッキング攻撃の仕組みをお見せします！」と言いました。

WPA/WPA2クラッキング
前述のとおり、WPA/WPA2クラッキングは、Wi-Fiトラフィックを傍受してデバイスとアクセスポイント間の4ウェイハンドシェイクをキャプチャすることから始まります。デバイスの接続または再接続には時間がかかる場合があるため、認証解除パケットを送信してクライアントを切断し、再接続させて新しいハンドシェイクを開始させ、それをキャプチャします。ハンドシェイクがキャプチャされると、攻撃者はキャプチャしたハンドシェイクファイルに対して総当たり攻撃または辞書攻撃を使用してパスワード（ PSK ）を解読できます。
```

```
攻撃者のネットワークカードがモニターモードで待機し、デバイスとアクセスポイント間のハンドシェイクを傍受する。
```

### 4者間握手

WPAパスワードクラッキングのプロセスは、Wi-FiネットワークのハンドシェイクをキャプチャしてPSK（パスワード）の復号を試みるものです。まず、攻撃者は無線アダプタをモニターモードにしてネットワークをスキャンし、次に特定のネットワークをターゲットにして4ウェイハンドシェイクをキャプチャします。ハンドシェイクがキャプチャされると、攻撃者はaircrack-ngなどのツールを使用してブルートフォース攻撃または辞書攻撃を実行し、ワードリストとパスフレーズを照合しようとします。

WPA 4ウェイハンドシェイクは、クライアントデバイス（スマートフォンやノートパソコンなど）とWi-Fiルーターが、安全な接続を確立する前に、両者が正しい「パスワード」または事前共有キー（PSK）を持っていることを確認するプロセスです。以下に、その手順を簡単に説明します。

- ルーターがチャレンジを送信する：ルーター（またはアクセスポイント）はクライアントに「チャレンジ」を送信し、ネットワークのパスワードを直接共有することなく、そのパスワードを知っていることを証明するように要求します。
- クライアントは暗号化された情報で応答します。クライアントはこのチャレンジを受け入れ、PSKを使用して暗号化された応答を作成します。ルーターのみが、自身も正しいPSKを持っているかどうかを検証できます。
- ルーターは検証を行い、確認応答を送信します。ルーターは、クライアントからの応答が期待どおりであることを確認した場合、クライアントが正しいPSKを持っていると判断します。その後、ルーターはクライアントに確認応答を返信します。
- 最終確認と接続確立：クライアントはルーターの応答を確認し、すべてが一致すれば、安全な接続の設定を完了します。

このハンドシェイクではPSK自体が直接開示されるわけではないが、PSKに依存する暗号化されたやり取りが行われる。

### 脆弱性

この脆弱性は、攻撃者がデバイスの接続時に傍受することで、この4ウェイハンドシェイクを傍受できるという点にあります。傍受したハンドシェイクデータを基に、攻撃者はオフラインでの総当たり攻撃や辞書攻撃を試みることができます。具体的には、様々なパスワードを試行し、それぞれが傍受したハンドシェイクデータを生成するかどうかを検証し、一致するものが見つかれば最終的にPSKを解読します。


デバイス／インターフェースはwlan2利用可能であり、この出力から得られる重要な情報が2つあります。

1. これは、当デバイスのMACアドレス/BSSIDaddrです。BSSIDはBasic Service Set Identifierの略で、無線デバイスまたはアクセスポイントの物理アドレスを識別するための固有の識別子です。
2. これは「管理モードtype」と表示されます。これは、ほとんどのWi-Fiデバイス（ノートパソコン、スマートフォンなど）がWi-Fiネットワークに接続するために使用する標準モードです。管理モードでは、デバイスはクライアントとして動作し、アクセスポイントに接続してネットワークに参加します。モニターモードと呼ばれる別のモードもありますが、これについては後ほど説明します。

ここには分析すべき情報がたくさんありますが、このデバイスがアクセスポイントであることを示す最も重要な詳細を以下に示します。

- デバイスのBSSIDとSSIDはそれぞれ と です。SSIDが表示されているということは、デバイスがネットワーク名をアドバタイズしていることを意味します。アクセスポイントは、クライアントがネットワークを検出して接続できるようにするために、ネットワーク名をアドバタイズします。02:00:00:00:00:00MalwareM_AP
- RSN（Robust Security Network）が存在するということは、ネットワークがWPA2を使用していることを示しています。RSNはWPA2規格の一部だからです。WPA2ネットワークでは通常、RSNを使用して暗号化と認証の設定を定義します。
- これらはCCMPGroup and Pairwise ciphersです。カウンターモード暗号ブロック連鎖メッセージ認証コードプロトコル（CCMP）は、WPA2で使用される暗号化方式です。
- Authentication suitesRSN内の値はPSKであり、これはWPA2-Personalネットワークであることを示しており、認証には共有パスワードが使用されます。
- もう1つの重要な詳細は、チャネル6DS Parameter setを示す値です。Wi-Fiにおけるチャネルとは、無線機器同士が通信できるようにする、より広いWi-Fiスペクトル内の特定の周波数範囲を指します。Wi-Fiチャネルにはさまざまな種類があり、それぞれがネットワークトラフィックをさまざまな周波数範囲に分散させ、干渉を低減するのに役立ちます。最も一般的なWi-Fiチャネルは2.4GHzと5GHzです。2.4GHz帯では、チャネル1、6、11が一般的に使用されます。これは、これらのチャネルが重複しないため、干渉が最小限に抑えられるためです。5GHz帯では、利用可能なチャネルがはるかに多く、より多くのネットワークが干渉なく共存できます。

ここで、一部のワイヤレス デバイスで使用できるもう 1 つのタイプ、モニターモードについて説明します。これは、主にネットワーク分析とセキュリティ監査に使用される特別なモードです。このモードでは、Wi-Fi インターフェイスは、デバイス宛てかどうかに関係なく、特定のチャネル上のすべてのワイヤレス トラフィックをリッスンします。ネットワークに参加することなく、範囲内のすべてのネットワーク トラフィックをパッシブにキャプチャして分析します。インターフェイスがwlan2モニター モードを使用できるかどうかを確認します。これを行うには、コマンドを実行しsudo ip link set dev wlan2 downてデバイスをオフにします。次に、を使用してモードを切り替えてsudo iw dev wlan2 set type monitor、wlan2 をモニター モードに変更します。次に、を使用してデバイスを再びオンにしますsudo ip link set dev wlan2 up。


```zsh
glitch@wifi:~$ sudo ip link set dev wlan2 down
glitch@wifi:~$ sudo iw dev wlan2 set type monitor
glitch@wifi:~$ sudo ip link set dev wlan2 up
```

最初の端末では、まずエリア内のWi-Fiトラフィックをキャプチャし、特にWPAハンドシェイクパケットをターゲットにします。これは、コマンドを使用して実行できますsudo airodump-ng wlan2。このコマンドは、近くのWi-Fiネットワーク（SSID）のリストを提供し、信号強度、チャネル、暗号化タイプなどの重要な詳細情報を表示します。これらの情報は、以前のコマンドですでにわかっています。

まず、現在ので、airodump-ngをキャンセルしてからCTRL+C、コマンドを実行しますsudo airodump-ng -c 6 --bssid 02:00:00:00:00:00 -w output-file wlan2。このコマンドは、トラフィックをキャプチャしたいアクセスポイントの特定のネットワークチャネルと MAC アドレス (BSSID) を対象とし、その情報を output-file という名前で始まるいくつかのファイルに保存します。これらのファイルは PSK の解読に使用されます。このコマンドの最終的な目的は、4 ウェイ ハンドシェイクをキャプチャすることです。まず、アクセスポイントに接続されている可能性のあるクライアントを確認します。クライアントが既に接続されている場合は、認証解除攻撃を実行できます。そうでない場合は、新しく接続するクライアントに対して 4 ウェイ ハンドシェイクをキャプチャします。この特定のシナリオでは、クライアントが既に接続されています。接続されたクライアントに関する情報を受信するまでは、出力は最初は同じように見えます。その情報は出力の下部に表示されます。攻撃が完了するまで、このコマンドを実行したままにしておくことが重要です。

```
glitch@wifi:~$ sudo airodump-ng -c 6 --bssid 02:00:00:00:00:00 -w output-file wlan2
BSSID              PWR RXQ  Beacons    #Data, #/s  CH   MB   ENC CIPHER  AUTH ESSID

 02:00:00:00:00:00  -28 100      631        8    0   6   54   WPA2 CCMP   PSK  MalwareM_AP  

 BSSID              STATION            PWR   Rate    Lost    Frames  Notes  Probes
```
