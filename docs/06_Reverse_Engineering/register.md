# REで最重要レジスタ
| レジスタ | 意味 |
|----------|------|
| RIP | 現在実行中の命令 |
| RSP | スタックの先頭 |
| RBP | 現在の関数フレーム |
| RAX | 戻り値 |
| RDI | 第1引数 |
| RSI | 第2引数 |
| RDX | 第3引数 |
| RFLAGS | 比較結果や条件分岐 |
# 同じレジスタの64bit・32bit・16bit・8bit版の名前一覧表

| 64bitレジスタ | 32bit | 16bit | 上位8bit | 下位8bit | 主な用途 |
|------------|--------|--------|---------|---------|---------|
| RAX | EAX | AX | AH | AL | 戻り値・演算 |
| RBX | EBX | BX | BH | BL | 汎用 |
| RCX | ECX | CX | CH | CL | カウンタ |
| RDX | EDX | DX | DH | DL | 汎用 |
| RSI | ESI | SI | - | SIL | 第2引数 |
| RDI | EDI | DI | - | DIL | 第1引数 |
| RBP | EBP | BP | - | BPL | ベースポインタ |
| RSP | ESP | SP | - | SPL | スタックポインタ |
| R8  | R8D  | R8W  | - | R8B  | 第5引数 |
| R9  | R9D  | R9W  | - | R9B  | 第6引数 |
| R10 | R10D | R10W | - | R10B | 汎用 |
| R11 | R11D | R11W | - | R11B | 汎用 |
| R12 | R12D | R12W | - | R12B | 汎用 |
| R13 | R13D | R13W | - | R13B | 汎用 |
| R14 | R14D | R14W | - | R14B | 汎用 |
| R15 | R15D | R15W | - | R15B | 汎用 |
| RIP | EIP | IP | - | - | 命令ポインタ |
| RFLAGS | EFLAGS | FLAGS | - | - | CPUフラグ |
