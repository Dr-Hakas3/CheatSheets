smbclient -L //192.168.0.115

![[smb(445)の調査 image.png]]

smbclientコマンドを使用して、リモートホスト上の共有リソースのリストを表示しています。

出力に示されているのは、リモートホスト 192.168.0.115 に接続し、現在のワークグループ WORKGROUP のパスワード認証を行っています。

arduinoCopy code

smbclient -L //192.168.0.115

次に、Password for \[WORKGROUP\root\]:のプロンプトが表示されています。

ここで、ワークグループ WORKGROUP 内の root ユーザーのパスワードを入力する必要があります。

出力結果には、共有フォルダの一覧とそのタイプ、コメントが表示されています。

具体的には、print$という名前のディスク共有（Printer Drivers）とIPC$という名前のIPCサービスが表示されています。

また、Reconnecting with SMB1 for workgroup listing.というメッセージが表示されています。

これは、ワークグループリストの取得時にSMB1プロトコルを使用することを示しています。

最後に、ServerとWorkgroupのセクションでは、サーバーとそのコメント、およびワークグループとそのマスターサーバーが表示されています。

この場合、192.168.0.115というサーバーがワークグループ WORKGROUP の一部であり、そのマスターサーバーは SEPPUKU であることが示されています。
