# What is the email address of the server certificate on wifi-global?

wifi-globalのサーバー証明書のメールアドレスは何ですか？

```
MGTネットワークとクライアントの間にTLSトンネルを確立する際、APは証明書を平文でクライアントに送信するため、誰でもその内容を確認できてしまいます。この情報は、RogueAP攻撃において同じフィールドを持つ偽の証明書を作成したり、企業のドメイン、社内メール、あるいはAPに関するその他の関連情報を入手したりするのに悪用される可能性があります。

まず、対象ネットワークのハンドシェイクを確実にキャプチャしてください。
```

```zsh
sudo airodump-ng wlan0 --band abg -c 44 --bssid F0:9F:C2:71:22:17 -w cap/wifi-global
```

```zsh
 tshark -r cap/wifi-global-01.cap -Y "wlan.bssid == F0:9F:C2:71:22:17 && eap && tls.handshake.certificate" -V | grep @
```
