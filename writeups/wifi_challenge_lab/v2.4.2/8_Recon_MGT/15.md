# What is the domain of the users of the wifi-regional network?

# 情報の確認

```zsh
sudo iw dev wlan0 set channel 44
```

```zsh
sudo airodump-ng wlan0 -w --manufacturer --wps --band abg
```

wifi-regionalのbssid

# 指定チャンネルのキャプチャ

```zsh
sudo airodump-ng wlan0 \
  --bssid F0:9F:C2:71:22:16 \
  -c 44 \
  -w cap/scan_ch44
```

```zsh
tshark -r cap/scan_ch44-01.cap \
  -Y 'wlan.bssid == f0:9f:c2:71:22:16 && eap' \
  -V
```

## キャプチャ内のeapのdomainとユーザの一覧

```zsh
tshark -r cap/scan_ch44-01.cap \
  -Y "eap.type == 1" \
  -T fields \
  -e frame.number \
  -e wlan.bssid \
  -e wlan.sa \
  -e eap.identity
```
