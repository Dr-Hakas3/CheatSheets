# What is the flag on the wifi-IT AP website?

WPA3 SAE を採用しているネットワークに、WPA2/WPA3 用に設定されたクライアントが存在する場合、そのクライアントに対してダウングレードを実行し、WPA2 を使用して当社のローグ AP に接続させることで、ハンドシェイクを取得し、後でそれを解読することができます（wifi-offices のケースと同様です）。
この場合、AP が SAE と PSK を使用していることが確認できるため、クライアントも PSK を受け入れる可能性があります。
この情報は、airodump-ngの「.csv」ファイルから取得できます。

bubblegum

```zsh
sudo wpa_supplicant -Dnl80211 -i wlan3 -c wifi-IT_connect.conf
```

wifi-IT_connect.conf

```
network={
    ssid="wifi-IT"
    key_mgmt=WPA-PSK
    psk="bubblegum"
}
```
