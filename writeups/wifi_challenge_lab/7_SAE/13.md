# wackerを初めて使う場合

# **Wacker：Git cloneからコンパイルまで**

今回の作業では、Wacker本体を取得したあと、Wackerが内部で使用する専用の `wpa_supplicant` をソースからビルドしました。

作業ディレクトリは以下です。

```
~/Tools/Wireless/Wi-Fi/wacker
```

## **1. 必要なビルドツールをインストール**

Kaliでコンパイルに必要なパッケージを導入します。

```
sudo apt update
sudo apt install -y build-essential pkg-config \
  libnl-3-dev libnl-genl-3-dev libssl-dev
```

- `build-essential`：gcc、makeなどのビルドツール
- `pkg-config`：ライブラリのコンパイルオプションを取得
- `libnl-3-dev` / `libnl-genl-3-dev`：Netlink関連ライブラリ
- `libssl-dev`：OpenSSL開発ライブラリ

## **2. WackerをGit clone**

今回の作業ディレクトリを作成して移動します。

```
mkdir -p ~/Tools/Wireless/Wi-Fi
cd ~/Tools/Wireless/Wi-Fi
```

```
git clone https://github.com/blunderbuss-wctf/wacker.git
cd wacker
```

## **3. wpa_supplicantの設定ファイルを作成**

Wackerのリポジトリには、専用に改変された `wpa_supplicant-2.10` が含まれています。

まず、設定テンプレート `defconfig` を `.config` としてコピーします。

```
sudo cp defconfig wpa_supplicant-2.10/wpa_supplicant/.config
```

- `defconfig`：ビルド設定のテンプレート
- `.config`：実際のコンパイルで使用する設定ファイル

## **4. パッチを適用**

リポジトリのルートディレクトリで実行します。

```
git apply wpa_supplicant.patch
```

このパッチは、Wackerから制御するための専用機能を `wpa_supplicant` に反映するものです。

## **5. コンパイル**

ソースコードのディレクトリへ移動します。

```
cd wpa_supplicant-2.10/wpa_supplicant
```

コンパイルを実行します。

```
make -j4
```

- `make`：`.config` の設定に従ってソースコードをコンパイル
- `-j4`：最大4つのジョブを並列実行

今回のログでは、最後に以下の表示まで到達しました。

```
LD  wpa_supplicant
```

これは `wpa_supplicant` のリンク処理まで進んだことを示しています。

## **6. 生成されたバイナリを確認**

Wackerのルートディレクトリに戻ります。

```
cd ~/Tools/Wireless/Wi-Fi/wacker
```

ファイルの存在と実行権限を確認します。

```
ls -lh wpa_supplicant-2.10/wpa_supplicant/wpa_supplicant
```

バージョン表示も確認します。

```
wpa_supplicant-2.10/wpa_supplicant/wpa_supplicant -v
```

## **全体のコマンド一覧**

次回、最初から構築する場合に使えるようにまとめると、以下のとおりです。

```
# 1. ビルド依存パッケージ
sudo apt update
sudo apt install -y build-essential pkg-config \
  libnl-3-dev libnl-genl-3-dev libssl-dev

# 2. Wacker取得
mkdir -p ~/Tools/Wireless/Wi-Fi
cd ~/Tools/Wireless/Wi-Fi
git clone https://github.com/blunderbuss-wctf/wacker.git
cd wacker

# 3. wpa_supplicantの設定
sudo cp defconfig wpa_supplicant-2.10/wpa_supplicant/.config

# 4. パッチ適用
git apply wpa_supplicant.patch

# 5. コンパイル
cd wpa_supplicant-2.10/wpa_supplicant
make -j4

# 6. バイナリ確認
cd ~/Tools/Wireless/Wi-Fi/wacker
ls -lh wpa_supplicant-2.10/wpa_supplicant/wpa_supplicant
```

**今回の重要ポイント**

最初にWackerを実行したときのエラーは、Wackerが内部で参照する次のバイナリが存在しなかったことが原因でした。

```
./wpa_supplicant-2.10/wpa_supplicant/wpa_supplicant
```

つまり、Wacker本体の取得だけでは不十分で、**専用の&#x20;**`wpa_supplicant`**&#x20;を設定・パッチ適用・コンパイルする必要がある**ということです。

この手順をWackerの構築手順としてチートシートに残しておくと、再構築時にも役立ちます。
