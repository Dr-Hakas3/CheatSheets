## 分析

```zsh
tshark -r ScanResult/15_scanc44-01.cap \
  -Y "eap.type == 1 && wlan.bssid == f0:9f:c2:71:22:16" \
  -T fields \
  -e frame.number \
  -e wlan.bssid \
  -e wlan.sa \
  -e eap.identity
```
