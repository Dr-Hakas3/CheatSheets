
# 17. What is the EAP method supported by the wifi-global AP?[](https://r4ulcl.com/posts/walkthrough-wifichallenge-lab-2.0/#17-what-is-the-eap-method-supported-by-the-wifi-global-ap)

有効なユーザーが見つかったら、各EAP認証方式を強制的に実行して、APがどの方式をサポートしているかを確認できます。
このタスクには「EAP_buster」を使用できます。

https://github.com/blackarrowsec/EAP_buster

## identityの特定

Using wifi_db:

![](https://r4ulcl.com/_astro/_SMXNmkl3_3F4O8ERRpg4Q.Buz_xt5v_Z1Al3uJ.webp)

```zsh
sudo bash ~/Tools/Wireless/Wi-Fi/EAP_buster/EAP_buster.sh wifi-global 'GLOBAL\GlobalAdmin' wlan1
```
