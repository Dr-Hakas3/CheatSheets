# 16. What is the email address of the server certificate?[](https://r4ulcl.com/posts/walkthrough-wifichallenge-lab-2.0/#16-what-is-the-email-address-of-the-server-certificate)

MGTネットワークとクライアント間のTLSトンネルを確立するために、APは証明書を平文でクライアントに送信するため、誰でもその内容を見ることができます。
この情報は、RogueAP攻撃で同じフィールドを持つ偽の証明書を作成したり、企業ドメイン、内部メール、またはAPに関するその他の関連情報を取得したりする際に悪用される可能性があります。
pcapFilter.shを使用すると、MGTを使用するAPが使用する証明書を表示できます。

https://gist.github.com/r4ulcl/f3470f097d1cd21dbc5a238883e79fb2

```zsh
bash ~/Tools/Wireless/Wi-Fi/pcapFilter/pcapFilter.sh -f ScanResult/15_scanc44-01.cap -C
```

![[Pasted image 20261123055953.png]]

```
Issuer: C=ES
		ST=Madrid
		L=Madrid
		O=WiFiChallengeLab
		OU=Certificate Authority
		CN=WiFiChallengeLab CA
		emailAddress=ca@WiFiChallengeLab.com
```

```
Subject: C=ES
		 L=Madrid
		 O=WiFiChallengeLab
	     OU=Server
	     CN=WiFiChallengeLab CA
	     emailAddress=server@WiFiChallengeLab.com
```

or tshark

```zsh
tshark -r ScanResult/15_scanc44-01.cap -Y "wlan.bssid == f0:9f:c2:71:22:15 && ssl.handshake.type == 11" -V
```

only Certificate

```
tshark -r ScanResult/15_scanc44-01.cap -Y "wlan.bssid == f0:9f:c2:71:22:15 && x509sat.IA5String" -T fields -e x509sat.IA5String
```
