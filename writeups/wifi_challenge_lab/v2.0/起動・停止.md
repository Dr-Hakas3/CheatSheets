WiFiChallengeLab v2.0 の起動・停止・再起動方法をまとめます。

作業ディレクトリは必ず以下を使用してください。

```
cd ~/CTF/WiFiChallengeLab-docker/v2.0
```

## **1. 起動方法**

次回からは、このコマンドだけで起動できます。

```
docker compose up -d aps clients db nzyme
```

Watchtowerは起動しません。現在のイメージバージョンを維持するためです。

## **2. 停止方法**

```
docker compose stop
```

- コンテナを停止する
    
- コンテナやDBデータは削除しない
    
- 次回 `up -d` で再開できる
    

## **3. 再起動方法**

```
docker compose restart aps clients db nzyme
```

すべての対象コンテナを再起動します。

## **4. 起動状態の確認**

```
docker compose ps
```

または

```
docker ps
```

## **5. ログの確認**

```
docker compose logs -f
```

終了するときは `Ctrl + C`。ログ表示だけが終了し、コンテナは停止しません。

## **コマンド早見表**

|操作|コマンド|
|---|---|
|起動|`docker compose up -d aps clients db nzyme`|
|停止|`docker compose stop`|
|再起動|`docker compose restart aps clients db nzyme`|
|状態確認|`docker compose ps`|
|ログ確認|`docker compose logs -f`|

## **注意点**

以下は通常の停止・起動では使用しないでください。

```
docker compose down
docker compose down -v
```

`down` はコンテナを削除します。`down -v` はボリュームも削除するため、DBデータを失う可能性があります。

**今後は「起動 → 演習 → 停止」の運用でOKです。**

**次回の起動手順**

```
cd ~/CTF/WiFiChallengeLab-docker/v2.0
docker compose up -d aps clients db nzyme
docker compose ps
```

**演習終了時**

```
docker compose stop
```
